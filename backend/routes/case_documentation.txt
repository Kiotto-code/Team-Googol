===========================================
POST /case/add
===========================================
Description:
Create a new case in the system.

Example Request:

{
  "box_id": 12,
  "receiver_id": 5,
  "receiver_image_url": "http://example.com/image.jpg",
  "item_id": 101,
  "status": "available",
  "case_close_at": null
}


Success Response:

{
  "message": "Case created successfully",
  "case_id": 1
}

===========================================
PUT /case/update?case_id=1
===========================================
Description:
Update details of an existing case by case_id. At least one updatable field must be provided.

Example Request:

{
  "status": "available_to_claim",
  "receiver_image_url": "http://example.com/new_image.jpg"
}


Success Response:

{
  "message": "Case updated successfully",
  "case_id": 1,
  "status": "available_to_claim",
  "receiver_id": "unchanged",
  "receiver_image_url": "http://example.com/new_image.jpg",
  "item_id": "unchanged",
  "case_close_at": "unchanged"
}

===========================================
POST /case/deposit-complete
===========================================
Description:
Mark a box as full and its related case as available_to_claim after deposit.

Example Request:

{
  "box_id": 12,
  "found_id": 1
}


Success Response:

{
  "message": "Deposit completed successfully",
  "box_id": 12,
  "case_id": 1,
  "box_status": "full",
  "case_status": "available_to_claim"
}

===========================================
POST /case/pickup-complete
===========================================
Description:
Mark a case as retrieved and free up the box.

Example Request:

{
  "box_id": 12,
  "found_id": 1
}


Success Response:

{
  "message": "Pickup completed successfully",
  "case_id": 1,
  "box_id": 12,
  "case_status": "retrieved",
  "box_status": true
}
