Lost & Found

Backend: FastAPI + SQLite. Basic endpoints:

Public API

  • GET /api/v1/items
  • POST /api/v1/users/register
  • POST /api/v1/users/login

Admin API

  • GET /api/v1/admin/users
  • GET /api/v1/admin/boxes
  • GET /api/v1/admin/cases
  • POST /api/v1/admin/items (JSON)
  • POST /api/v1/admin/items/upload (multipart)

API Docs
